# Trinethra Feedback Analyzer

AI-assisted supervisor transcript analysis tool built using React.js, Node.js, Express.js, Ollama and Llama 3.2.

## Features

- Sentiment analysis
- Rubric scoring
- KPI mapping
- Gap analysis
- Follow-up question generation

## Tech Stack

- React.js
- Node.js
- Express.js
- Ollama
- Llama 3.2

## Run Project Locally

```bash
# Clone repository
git clone https://github.com/rohitbhalla46/trinethra-feedback-analyzer.git

# Start frontend
cd frontend
npm install
npm run dev

# Start backend (open new terminal)
cd backend
npm install
node server.js

# Run AI model using Ollama
ollama run llama3.2
