# Trinethra Feedback Analyzer

AI-assisted supervisor transcript analysis tool built using React, Node.js, Express, and Ollama LLM.

---

## Features

- AI-powered transcript analysis
- Sentiment evidence extraction
- Rubric scoring system
- KPI mapping
- Gap analysis
- Follow-up question generation
- Local LLM integration using Ollama

---

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS

Backend:
- Node.js
- Express.js

AI Model:
- Ollama
- Llama 3.2

---

## Project Structure

frontend/
backend/

---

## Installation

### Backend Setup

cd backend

npm install

node server.js

---

### Frontend Setup

cd frontend

npm install

npm run dev

---

## Ollama Setup

Install Ollama from:

https://ollama.com/download

Run:

ollama pull llama3.2

ollama run llama3.2
